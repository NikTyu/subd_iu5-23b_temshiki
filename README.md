# Описание проекта

Проект представляет собой собственную реляционную СУБД, разработанную на языке C++.

Система поддерживает базовые SQL-запросы:
- CREATE DATABASE
- DROP DATABASE
- CREATE TABLE
- DROP TABLE
- INSERT
- SELECT
- UPDATE
- DELETE

Данные сохраняются между запусками программы с использованием файлового хранения.

---

# Используемые технологии

- C++
- STL
- CMake
- Bash
- Файловое хранение данных

---

# Паттерн проектирования

В проекте используется паттерн Singleton.

Паттерн применяется в классе `DatabaseManager` для обеспечения единого экземпляра менеджера базы данных.

# Структура проекта

```text
src/                — исходный код
build/              — собранный проект
data/               — хранение данных
build.sh            — сборка проекта
run.sh              — запуск проекта
CMakeLists.txt      — конфигурация сборки
```

# Пример работы

## Создание базы данных

```sql
CREATE DATABASE test;
```

---

## Создание таблицы

```sql
CREATE TABLE users (id INT, name TEXT);
```

---

## Добавление данных

```sql
INSERT INTO users VALUES (1, 'John');
```

```sql
INSERT INTO users VALUES (2, 'Jane');
```

---

## Выборка данных

```sql
SELECT * FROM users;
```

Результат:

```text
id,name
1,John
2,Jane
```

# Постоянное хранение данных

Все таблицы сохраняются в папке `data/`.

После повторного запуска программы данные остаются доступными.

# Интерфейс

Система использует консольный интерфейс.

После запуска пользователь вводит SQL-запросы вручную:

